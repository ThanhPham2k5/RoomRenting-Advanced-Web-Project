## 📌 Giới thiệu dự án (Overview)

**Room Renting System** là nền tảng web kết nối trực tiếp giữa **Chủ nhà trọ (Landlord)** và **Người thuê phòng (Tenant / Student)**. Hệ thống giúp tối ưu hóa quá trình tìm kiếm, đăng tin nhanh chóng, minh bạch.

### 🎯 Các tính năng chính (Key Features)

#### 👤 Dành cho Người thuê (Tenant / Student):
- 🔍 **Tìm kiếm & Lọc nâng cao:** Tìm phòng theo khu vực, mức giá, diện tích, tiện ích đi kèm (Wifi, máy lạnh, chỗ để xe...).
- 🗺️ **Xem chi tiết phòng:** Hình ảnh thực tế, thông tin giá điện/nước, vị trí trên bản đồ và thông tin liên hệ chủ trọ.
- 💬 **Đánh giá & Bình luận:** Phản hồi trải nghiệm thực tế về phòng trọ và thái độ chủ nhà.

#### 🏡 Dành cho Chủ trọ (Landlord):
- 📝 **Đăng tin & Quản lý bài đăng:** Tạo mới, chỉnh sửa, ẩn/hiện tin đăng cho thuê phòng.

#### 🛡️ Dành cho Quản trị viên (Admin):
- 👥 **Quản lý người dùng:** Duyệt tài khoản chủ trọ, quản lý danh sách người dùng.
- 🚫 **Kểm duyệt tin đăng:** Duyệt bài đăng mới trước khi hiển thị công khai để đảm bảo chất lượng.

## 🛠️ Công nghệ sử dụng (Tech Stack)

- **Backend & Frontend:** PHP (Server-Side Rendering)
- **Database:** MySQL
- **Interface & Styling:** HTML5, CSS3, JavaScript
- **Database Seeder:** PHP Script / PDO / Database Migration & Seeding (Khởi tạo dữ liệu mẫu tự động)
- **Web Server Tools:** XAMPP / Laragon
